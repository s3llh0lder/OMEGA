# Mini Casino Frontend

React + TypeScript frontend for the Mini Casino application.

## Quick Start

### Prerequisites
- Node.js 18+
- npm or yarn

### Run the Application

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The application will open at `http://localhost:5173`

## Build for Production

```bash
npm run build
```

The build output will be in the `dist/` folder.

## Tech Stack

- React 18
- TypeScript
- Vite
- React Router v6
- Context API + useReducer
- React Hook Form
- localStorage for persistence
